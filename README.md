# DroidCraft 🤖

A drag-and-drop Android app builder that runs entirely on your phone.

## 🚀 Download the APK

Every push to `main` automatically builds a beta APK.

👉 **[Download latest APK](../../actions/workflows/build.yml)**

1. Open the latest successful build
2. Scroll down to **Artifacts**
3. Download `droidcraft-debug-apk.zip`
4. Unzip → install `app-debug.apk` on your Android phone
5. Allow "Install from unknown sources" if prompted

## ✨ Features

- 🔐 Multi-user accounts with quick login
- 📱 Multi-screen projects with drag-to-reorder
- 🎨 12+ UI components
- 💅 Rich styling (colors, fonts, corners, padding)
- 🔗 Screen-to-screen navigation
- 📄 XML code export
- 💾 Auto-save + backup/restore
- 🌙 Dark mode

## 🛠️ Built With

- Pure HTML/CSS/JS builder (in `index.html`)
- Kotlin + WebView for the Android wrapper
- Gradle + Android SDK (via GitHub Actions)
